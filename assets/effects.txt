# SFPS particle effects
#
# Spawned by name from code: fx_spawn("spark", point, normal).
#
#   e <name>            starts a definition; everything after it belongs to it
#   count <n>           particles per spawn
#   life <ms>           how long each particle lives
#   size <born> <dead>  edge length in centimetres, interpolated over the life
#   rgb <r> <g> <b>     colour at birth, 0..255
#   rgb2 <r> <g> <b>    colour at death. Omit and the birth colour is held.
#                       A spark cooling white -> orange, or blood darkening as
#                       it falls, says what the thing WAS; an alpha fade alone
#                       only says that it is ending
#   alpha <born> <dead> opacity in percent, interpolated over the life
#   speed <v> <spread>  initial speed along the spawn normal, cm/s, +/- spread.
#                       spread also scatters the DIRECTION: a large spread
#                       relative to speed reads as a burst, a small one as a jet
#   spawn <r>           radius the burst starts from, cm. THE parameter for
#                       making a burst read as separate particles: from a
#                       single point they overlap while still large, and two
#                       overlapping additive quads at 90% alpha composite to
#                       99.7% -- a dozen sparks become one white blob
#   drag <pct>          speed lost per second, percent. 0 flies at a constant
#                       rate and reads as an expanding shell; a high value
#                       shoots out and settles, which is what debris does
#   spin <deg>          degrees per second each particle rolls. Even at 0 the
#                       starting angle is randomised, because identically
#                       oriented squares line their edges up and read as one
#                       shape being scaled
#   gravity <a>         downward acceleration, cm/s^2. 0 floats, 900 falls
#   blend add|alpha     `add` glows and never darkens; `alpha` can be dark
#   face camera|normal   `camera` always faces you; `normal` lies flat on the
#                       surface it was spawned against -- that is a decal
#   dome 1              every particle at ONE speed over the hemisphere around
#                       the normal, so the front is an edge you can see rather
#                       than a smear. For anything whose RADIUS is a fact
#   disc 1              the dome's equator: one speed around the ring
#                       perpendicular to the normal. With `face normal` the
#                       quads lie in that plane too, so a disc spawned against
#                       a floor is a ring of light running out across it. The
#                       dome cannot do this -- half of it leaves the ground
#
# Every number is an integer. Unknown keywords are skipped rather than
# rejected, so a file written for a newer build still loads in an older one.
#
# Editing this file updates the running game (dev builds): the definitions are
# re-read and live particles are dropped, so a change is visible on the next
# shot rather than the next launch.
#
# 이 파일을 수정하면 실행 중인 게임에 반영됩니다(개발 빌드). 정의를 다시 읽고 살아 있는
# 입자는 버리므로, 변경 사항은 다음 실행이 아니라 다음 발사에서 확인됩니다.

# --- weapon impacts ---------------------------------------------------------

# Sparks off a wall. Additive so they read as light against dark stone, and
# fast with a wide spread so the burst looks like it came off the surface.
e spark
  count 7
  life 260
  size 11 1
  rgb 255 232 170
  rgb2 220 90 20         # white-hot, cooling to ember orange
  alpha 85 0
  speed 340 280
  spawn 6
  drag 150               # sparks lose speed fast; they are small and light
  spin 540
  gravity 420
  blend add
  face camera

# The same event seen on flesh. Slower, heavier, and it falls -- blood arcs
# where sparks fly. Alpha-blended because it must be able to be darker than
# what is behind it, which additive can never be.
e blood
  count 9
  life 520
  size 10 3
  rgb 175 20 16
  rgb2 70 8 8            # darkens as it falls, the way blood does
  alpha 92 0
  speed 220 185
  spawn 9
  drag 60
  spin 260
  gravity 900
  blend alpha
  face camera

# The mark left behind. One particle, no motion, and a long life: this is a

# the wall instead of turning to follow the camera.
e bullethole
  count 1
  life 6000
  size 9 9
  rgb 12 10 9
  alpha 85 0
  speed 0 0
  gravity 0
  blend alpha

# --- lava ---------------------------------------------------------------

# Smoke boiling off a lava floor. Spawned by main.c at points sampled across
# the hazard sectors, not by any impact -- see the lava smoke block there for
# why the sampling is what it is.
#
# NEGATIVE gravity is what makes it rise, and it is the whole effect: hot gas
# is buoyant, so it accelerates upward rather than merely being thrown that
# way. Launching it up with `speed` alone and letting it coast would slow to a
# stop and hang, which reads as steam in a vacuum. `speed` is kept low for the
# same reason -- the rise should come from the buoyancy, not the throw.
#
# `alpha` peaks low: this sits on top of a surface that is already the
# brightest thing in the room, and smoke opaque enough to be obvious hides the
# lava it is supposed to be coming from.
#
# `blend alpha`, NOT add: smoke is the one thing here that must be able to be
# DARKER than what is behind it. Additive smoke over lava glows, which is a
# contradiction -- it is soot.
#
# 용암 바닥에서 끓어오르는 연기입니다. 충돌이 아니라 main.c가 위험 지형 섹터 전체에서
# 표본 추출한 지점에 생성합니다. 표본 추출 방식의 이유는 그곳의 용암 연기 블록을
# 참조하십시오.
#
# *음수* 중력이 상승을 만들며 그것이 이 효과의 전부입니다. 뜨거운 기체는 부력을 받으므로
# 단지 위로 던져지는 것이 아니라 위로 가속합니다. `speed`만으로 쏘아 올려 관성으로
# 두면 점점 느려지다 멈춰 매달리는데, 이는 진공 속의 수증기처럼 읽힙니다. 같은 이유로
# `speed`를 낮게 유지합니다. 상승은 던지기가 아니라 부력에서 나와야 합니다.
#
# `alpha`의 정점이 낮습니다. 이것은 방에서 이미 가장 밝은 표면 위에 놓이며, 눈에 띌 만큼
# 불투명한 연기는 정작 그것이 피어오르는 용암을 가립니다.
#
# `blend add`가 아니라 `alpha`입니다. 연기는 이곳에서 뒤에 있는 것보다 *어두울* 수
# 있어야 하는 유일한 대상입니다. 용암 위의 가산 연기는 빛나게 되는데, 그것은 모순입니다.
# 그을음이기 때문입니다.
e lavasmoke
  count 1                # one puff per spawn -- world.c paces the rate
  life 4200              # LONG. Density here is accumulation: a puff has to
                         # still be in the air when the next several arrive, or
                         # the room never fills and each puff reads on its own.
  size 34 150            # and it has to get BIG. Coverage per draw call is the
                         # cheap half of "thick" -- every particle is its own
                         # draw call (see fx.c), so widening one costs nothing
                         # where adding one costs a call.
  rgb 96 74 62           # warm soot, lit from below by what it came off
  rgb2 44 42 46          # cooling to a neutral grey as it climbs
  alpha 26 0             # FAINTER than before, deliberately. Thickness should
                         # come from many thin layers overlapping, not from a
                         # few opaque ones -- opaque puffs read as blobs
                         # crossing each other, thin ones read as air.
  speed 45 26            # gentler still: it should hang, not travel
  spawn 26               # scattered, so a run of puffs is not a column
  drag 70                # bleeds the initial push off sooner, so it stalls and
                         # spreads instead of climbing out of the room
  spin 24                # slow roll; smoke turns over, it does not tumble
  gravity -55            # still NEGATIVE, but slower: smoke that rises fast
                         # leaves, and what leaves cannot be thick
  blend alpha            # must be able to be darker than the lava behind it
  face camera

# --- the blast, in layers ---------------------------------------------------
#
# One effect cannot be an explosion. DarkPlaces builds TE_EXPLOSION out of six
# passes -- a scorch decal, a light, big embers, a core, a rising smoke plume
# and small sparks -- and the reason is that each one answers a different
# question: how big, how hot, how long ago, and how far.
#
# Ours answers the one that matters for play first: HOW FAR. `blastdome` is
# authored for a radius of one metre and fx_spawn_scaled multiplies it by the
# real blast radius, so the shell arrives exactly where the damage stops.
#
# 하나의 이펙트는 폭발이 될 수 없습니다. DarkPlaces는 TE_EXPLOSION을 여섯 겹으로 쌓으며,
# 이유는 각 겹이 서로 다른 질문에 답하기 때문입니다. 얼마나 큰가, 얼마나 뜨거운가,
# 얼마나 지났는가, 그리고 얼마나 먼가. 우리 것은 플레이에 중요한 것부터 답합니다.
# 얼마나 먼가입니다.

# --- the arena tells you where ---------------------------------------------
#
# THE ONLY EFFECT HERE THAT IS A PROMISE RATHER THAN A CONSEQUENCE. Everything
# else in this file happens because something already happened -- a shot landed,
# a body fell. This one says something is ABOUT to, and it has SPAWN_WARN_TIME
# to say it in, so it is read under pressure by a player who is looking
# somewhere else.
#
# So it is built to be seen from the corner of an eye rather than to be pretty:
# a rising column, not a burst. `spawn 40` puts the particles around the mouth
# rather than at a point, negative gravity makes them climb, and the low drag
# keeps them climbing for the whole life instead of settling -- a shape that
# grows upward is the one that catches peripheral vision, which is the whole
# job. Additive and violet because nothing else in this palette is: every other
# effect here is fire, blood or smoke, so the one colour that means "not a
# consequence" is the one no consequence uses.
#
# life 550 against SPAWN_WARN_TIME's 0.55s, so the column is still there when
# the monsters land in it. A warning that has faded before the thing it warned
# about is a warning nobody connected to anything.
#
# 이곳에서 유일하게 결과가 아니라 *예고*인 이펙트입니다. 이 파일의 다른 모든 것은 이미 무슨
# 일이 일어났기 때문에 일어납니다. 탄이 박혔고, 몸이 쓰러졌습니다. 이것은 무언가가 *일어날
# 것*이라고 말하며, 말할 시간은 SPAWN_WARN_TIME뿐이고, 다른 곳을 보고 있는 플레이어가 압박
# 속에서 읽습니다.
#
# 그래서 예쁘기보다 곁눈으로 보이도록 만들었습니다. 폭발이 아니라 솟아오르는 기둥입니다.
# `spawn 40`이 입자를 한 점이 아니라 입구 둘레에 놓고, 음수 중력이 그것들을 올라가게 하며,
# 낮은 drag가 가라앉는 대신 수명 내내 계속 오르게 합니다. 위로 자라는 형태가 주변시에 걸리는
# 형태이며 그것이 이 이펙트의 일 전부입니다. 가산 합성에 보라색인 이유는 이 팔레트에서 다른
# 무엇도 그렇지 않기 때문입니다. 이곳의 다른 이펙트는 전부 불·피·연기이므로, "결과가 아님"을
# 뜻할 색은 어떤 결과도 쓰지 않는 색입니다.
#
# SPAWN_WARN_TIME의 0.55초에 대해 life 550입니다. 몬스터가 그 안으로 내려설 때 기둥이 아직
# 있어야 합니다. 예고한 대상보다 먼저 사라진 예고는 아무도 무엇과도 연결하지 못한 예고입니다.
e spawnwarp
count 30
life 550
size 11 2
rgb 176 108 255
rgb2 74 26 150
alpha 90 0
speed 150 60
spawn 40
drag 20
gravity -110
spin 90
blend add

# The mouth the column rises out of. `spawnwarp` alone is a vertical thing in
# mid-air and says WHEN but not WHERE: the player reads "something over there"
# and still has to guess how much floor is about to be occupied. This draws the
# footprint.
#
# `dome 1` with gravity PULLING DOWN is the ground-ring idiom `landdust` uses --
# the shell is thrown out evenly, the fall flattens it, and what is left is a
# rim on the floor rather than a ball in the air. No jitter on the speed,
# because a dome's whole value is that the edge arrives all at once and can be
# read as a distance.
#
# life 550 for the same reason spawnwarp has it: the mouth must still be open
# when the thing it opened for arrives.
#
# 기둥이 솟아오르는 *입구*입니다. `spawnwarp`만으로는 공중에 뜬 수직 형상이어서 *언제*는
# 말하지만 *어디*는 말하지 않습니다. 플레이어는 "저쪽에 뭔가 있다"까지만 읽고, 바닥이 얼마나
# 점거될지는 여전히 짐작해야 합니다. 이것이 그 발자국을 그립니다.
#
# 중력을 *아래로* 준 `dome 1`은 `landdust`가 쓰는 지면 고리 기법입니다. 껍질을 고르게 던지고
# 낙하가 그것을 납작하게 만들어, 공중의 공이 아니라 바닥의 테두리가 남습니다. 속력에 흔들림을
# 주지 않는 이유는, 돔의 가치 전부가 가장자리가 한꺼번에 도달하여 *거리로 읽힌다*는 데 있기
# 때문입니다.
#
# spawnwarp와 같은 이유로 life 550입니다. 입구는 그것이 열린 목적이 도착할 때까지 열려 있어야
# 합니다.
e spawnring

rgb 205 150 255

alpha 66 0             # under the column: this frames it, it does not compete
speed 260 0            # dome: no jitter, so the rim arrives together
spawn 14
drag 190               # opens fast, then holds at the rim
spin 30
gravity 300            # pulls the shell onto the floor -- a ring, not a ball

blend add

# THE ARRIVAL. Everything above this is a promise; this is the only part that
# fires because something actually happened, and it fires ONLY when a monster
# was really made -- see spawners_update. A flash over an empty floor would
# teach the player to flinch at nothing, which is worse than no flash at all.
#
# Hotter and whiter than the warning ever gets. The telegraph lives in the
# 176..205 purple range and never brightens; this opens at near-white and cools
# back down into that same purple, so the burst reads as the portal discharging
# rather than as a second, unrelated effect.
#
# Short on purpose -- 300ms against the warning's 550. A punctuation mark, not
# a cloud: the monsters are the thing to look at now, and an effect still
# blooming over them is an effect hiding the fight it announced.
#

# --- explosion shards -------------------------------------------------------
# The low-poly explosion look, in the terms this engine has. There is no mesh
# VFX path here and no sprite-sheet animation -- an effect is camera-facing
# quads with a size ramp -- so what carries the read is the SHAPE OF THE EVENT
# rather than the geometry: a hard additive flash, opaque tumbling chunks that
# fall, and the existing dome and smoke around them. Chunks are what separate
# an explosion from a glow; they are drawn `blend alpha` on purpose, because a
# piece of debris occludes what is behind it and light does not.
#
# COLOUR FOLLOWS THE PROJECTILE, which is the whole point of there being two of
# these. The grenade burns orange, so its shards are hot metal cooling to
# scorched iron; the monster's bolt is blue -- scene_draw_shots paints the halo
# (0.10,0.42,0.85) and boltburst already cools into it -- so its shards are the
# same blue. Sharing one effect between them, which detonate used to do with
# boltburst, put blue sparks in a grenade blast.
#
# 이 엔진이 가진 용어로 옮긴 로우 폴리 폭발 외형입니다. 이곳에는 메시 VFX 경로도 스프라이트
# 시트 애니메이션도 없으며 이펙트란 크기 램프를 가진 카메라 지향 사각형입니다. 그래서 읽기를
# 만드는 것은 지오메트리가 아니라 *사건의 형태*입니다. 단단한 가산 섬광, 떨어지는 불투명한
# 조각들, 그리고 그 주위의 기존 돔과 연기입니다. 조각이야말로 폭발과 발광을 가르는 것이며,
# 의도적으로 `blend alpha`로 그립니다. 파편은 뒤를 가리고 빛은 가리지 않기 때문입니다.
#
# *색은 발사체를 따릅니다.* 이것이 둘로 나뉜 이유 전부입니다. 유탄은 주황으로 타므로 그 조각은
# 식어 가는 뜨거운 금속이고, 몬스터의 볼트는 파랗기에(scene_draw_shots가 헤일로를
# (0.10,0.42,0.85)로 칠하고 boltburst도 이미 그 색으로 식습니다) 그 조각도 같은 파랑입니다.

# --- the altar --------------------------------------------------------------
#
# WHAT AN ALTAR IS FOR. A wave reward thrown at the player's feet is collected
# without a decision -- you are already standing on it. loot.txt can throw it
# somewhere else instead, and the moment it does, the drop point has a problem
# the old one never had: it is across the room, and nothing about the room says
# which part of it is the one you were paid at. Six seconds of breather is not
# long enough to search.
#
# So the spot announces itself, in three layers, for the same reason the blast
# is four: each answers a different question. WHERE (the ring, running out
# across the floor at the instant the wave ends -- motion at the edge of vision
# is what turns the head), WHAT (the core, a warm column that says shrine and
# not explosion), and STILL HERE (the motes, paced by world.c for as long as
# the shrine burns, because the ring and the core are over in half a second and
# the player has six).
#
# Warm gold throughout, and deliberately not the blue every other bright thing
# in this game is. A bolt is blue, the hook is blue, a caster's burst cools into
# blue -- all of them things that are about to hurt. The one thing in the room
# that is a REWARD should not be drawn in the colour of the things that are not.
#
# 제단은 무엇을 위한 것인가. 플레이어의 발치에 던져진 웨이브 보상은 결정 없이 획득됩니다.
# 이미 그 위에 서 있기 때문입니다. loot.txt는 그것을 다른 곳에 던질 수 있으며, 그 순간
# 낙하 지점은 예전에는 없던 문제를 갖게 됩니다. 방 건너에 있는데, 방의 어느 것도 어느
# 부분이 보상받은 자리인지 말해 주지 않습니다. 6초의 휴식은 찾아다니기에 충분하지 않습니다.
#
# 그래서 그 자리가 스스로를 알리며, 폭발이 네 겹인 것과 같은 이유로 세 겹입니다. 각 겹이
# 서로 다른 질문에 답합니다. *어디인가*(웨이브가 끝나는 순간 바닥을 가로질러 퍼지는 고리.
# 시야 가장자리의 움직임이 고개를 돌리게 합니다), *무엇인가*(폭발이 아니라 제단이라고
# 말하는 따뜻한 기둥인 코어), 그리고 *아직 여기 있다*(제단이 타오르는 동안 world.c가
# 조절해 뿌리는 티끌. 고리와 코어는 0.5초면 끝나지만 플레이어에게는 6초가 있기 때문입니다).
#
# 전체가 따뜻한 금색이며, 이 게임의 다른 모든 밝은 것이 쓰는 파랑이 의도적으로 아닙니다.
# 볼트가 파랗고, 갈고리가 파랗고, 캐스터의 폭발이 파랑으로 식습니다. 전부 곧 아프게 할
# 것들입니다. 방에서 유일하게 *보상*인 것이 그렇지 않은 것들의 색으로 그려져서는 안 됩니다.

# WHERE. Speed x life = 300cm, so the ring stops three metres out -- far enough
# to be seen past whatever is between you and it, near enough that it does not
# read as something happening to the whole room. `face normal` is what keeps it

  gravity 0
  blend add
  face normal

# --- what a floor item gives off --------------------------------------------
#
# WHAT THIS REPLACED, and why the replacement is smaller. A floor item used to
# carry an additive halo drawn behind its sprite plus a dynamic light while it
# was fresh. Both worked -- the item was visible from the far end of a hall --
# and both were the wrong kind of visible: a glowing disc standing in the air
# is a LAMP, and this game already spends that language on the things that are
# about to hurt you. A bolt glows. The hook glows. A muzzle glows. An item that
# glows the same way is asking to be read as one of those, and it does it
# while parked, forever, which none of them do.
#
# Motes rising off it say the same thing with none of that. They are small, so
# nothing reads as a light source; they MOVE, which is what actually catches
# the eye at distance -- a static glow competes with every lit surface in the
# room, and drifting specks compete with nothing; and they leave the item's own
# drawing completely untouched, so what says WHICH item this is is never sitting
# inside what says WHERE it is.
#
# 무엇을 대체했으며, 왜 대체물이 더 작은가. 바닥 아이템은 스프라이트 뒤에 그려지는 가산
# 헤일로와, 갓 도착했을 때의 동적 광원을 지니고 있었습니다. 둘 다 동작했고(복도 저편에서도
# 아이템이 보였습니다) 둘 다 잘못된 종류의 보임이었습니다. 공중에 서 있는 빛나는 원반은
# *등*이며, 이 게임은 그 언어를 이미 당신을 아프게 할 것들에 쓰고 있습니다. 볼트가
# 빛납니다. 갈고리가 빛납니다. 총구가 빛납니다. 같은 방식으로 빛나는 아이템은 그것들 중
# 하나로 읽히기를 청하는 것이며, 게다가 세워진 채로 영원히 그럽니다. 그중 무엇도 그러지
# 않습니다.
#
# 아이템에서 피어오르는 티끌은 그것 없이 같은 말을 합니다. 작아서 광원으로 읽히는 것이
# 없고, *움직이므로* 멀리서 실제로 눈길을 끕니다(정적인 발광은 방의 모든 밝은 표면과
# 경쟁하지만 떠다니는 알갱이는 무엇과도 경쟁하지 않습니다). 그리고 아이템 자신의 그림을
# 전혀 건드리지 않으므로, *어느* 아이템인지 말해 주는 것이 *어디에* 있는지 말해 주는 것
# 안에 갇히는 일이 없습니다.

# One mote per spawn; pickup.c paces the rate for every item on the floor, the
# same arrangement lavasmoke has with world.c. NEGATIVE gravity is the whole
# effect: the rise has to come from buoyancy rather than from a throw, or the
# specks slow to a stop at the top of their arc and hang there, which reads as
# dust in a jar. `speed` stays low for the same reason.
#
# Pale green, which is the colour `pickup` fades to when one is collected --
# so the mark an item leaves in the air and the burst it makes when taken are
# the same colour, and a player who has picked up one thing has already been
# taught what these specks mean.
#
# 생성당 티끌 하나이며, 바닥의 모든 아이템에 대해 pickup.c가 빈도를 조절합니다. lavasmoke가
# world.c와 맺는 것과 같은 배치입니다. *음수* 중력이 이 효과의 전부입니다. 상승은 던지기가
# 아니라 부력에서 나와야 하며, 그러지 않으면 알갱이가 포물선 꼭대기에서 멈춰 매달리는데
# 그것은 병 속의 먼지로 읽힙니다. 같은 이유로 `speed`는 낮게 유지합니다.
#
# 옅은 초록이며, 아이템을 획득했을 때 `pickup`이 사그라드는 색입니다. 아이템이 공중에
# 남기는 표식과 획득될 때 내는 폭발이 같은 색이 되므로, 하나라도 주워 본 플레이어는 이
# 알갱이들이 무엇을 뜻하는지 이미 배운 셈입니다.

# A shot that did not land. The maw takes no damage while a single ward
# stands, and enemy.c withholds the hit flash for it deliberately -- the flash
# is how this game says "you are hurting it", and a boss that flashes while its
# health bar correctly refuses to move reads as a broken bar rather than as an
# invulnerable enemy.
#
# So this is the sentence the flash is not allowed to say. It has to read as a
# REFUSAL at a glance and from any range: cold where blood is warm, thrown back
# toward the shooter rather than away, and gone in a fifth of a second so it
# cannot be mistaken for something burning. `blend add` over a dark body makes
# it a flare on the surface instead of a stain in it.
#
# 닿지 않은 사격입니다. 결계핵이 하나라도 서 있는 동안 아귀는 피해를 받지 않으며, enemy.c는
# 그에 대해 피격 섬광을 의도적으로 억제합니다. 섬광은 이 게임이 "네가 그것을 아프게 하고
# 있다"고 말하는 방식이고, 체력바가 (올바르게) 움직이기를 거부하는데 섬광만 번쩍이는 보스는
# 무적인 적이 아니라 고장 난 바로 읽힙니다.
#
# 그래서 이것은 섬광이 말해서는 안 되는 그 문장입니다. 어느 거리에서든 한눈에 *거절*로
# 읽혀야 합니다. 피가 따뜻한 곳에서 차갑고, 바깥이 아니라 쏜 쪽으로 튕겨 나가며, 타는 것으로
# 오인될 수 없도록 5분의 1초 만에 사라집니다. 어두운 몸통 위의 `blend add`는 이것을 표면에
