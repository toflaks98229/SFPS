# SFPS particle effects
#
# Spawned by name from code: fx_spawn("spark", point, normal).
#
#   e <name>            starts a definition; everything after it belongs to it
#   count <n>           particles per spawn
#   life <ms>           how long each particle lives
#   size <born> <dead>  edge length in centimetres, interpolated over the life
#   rgb <r> <g> <b>     colour at birth, 0..255
#   rgb2 <r> <g> <b>    colour at death. Omit and the birth colour is held.
#                       A spark cooling white -> orange, or blood darkening as
#                       it falls, says what the thing WAS; an alpha fade alone
#                       only says that it is ending
#   alpha <born> <dead> opacity in percent, interpolated over the life
#   speed <v> <spread>  initial speed along the spawn normal, cm/s, +/- spread.
#                       spread also scatters the DIRECTION: a large spread
#                       relative to speed reads as a burst, a small one as a jet
#   spawn <r>           radius the burst starts from, cm. THE parameter for
#                       making a burst read as separate particles: from a
#                       single point they overlap while still large, and two
#                       overlapping additive quads at 90% alpha composite to
#                       99.7% -- a dozen sparks become one white blob
#   drag <pct>          speed lost per second, percent. 0 flies at a constant
#                       rate and reads as an expanding shell; a high value
#                       shoots out and settles, which is what debris does
#   spin <deg>          degrees per second each particle rolls. Even at 0 the
#                       starting angle is randomised, because identically
#                       oriented squares line their edges up and read as one
#                       shape being scaled
#   gravity <a>         downward acceleration, cm/s^2. 0 floats, 900 falls
#   stretch <ms>        draw the quad over this many milliseconds of the
#                       particle's OWN travel, along its velocity. A streak
#                       instead of a square, and one that SHORTENS as `drag`
#                       takes the speed away, which is what reads as a spark
#                       landing rather than merely fading. 0 is the square.
#                       Ignored by `face normal` -- a decal has no velocity
#                       worth pointing at
#   trail <name>        the effect this particle leaves BEHIND it as it flies,
#                       every `trailms` milliseconds. What makes a thrown ember
#                       read as thrown: a bright dot arcing across a dark room
#                       is a dot moving, and the same dot with a metre of smoke
#                       behind it is something the blast HURLED. The chain is
#                       one deep -- a wake never has a wake -- so a definition
#                       may safely name one that names it back
#   trailms <ms>        how often, in milliseconds. What is alive at once is
#                       `life` of the wake divided by this, per particle, and
#                       THAT is the number to budget against the shared pool
#   blend add|alpha     `add` glows and never darkens; `alpha` can be dark
#                       ONE WORD, NOT A NUMBER. `blend 1` parses -- unknown
#                       tokens are skipped rather than rejected, and `1` is
#                       simply not `add` -- and lands on `alpha`, which is the
#                       opposite of what anyone writing it meant. Three
#                       definitions in this file had it for a long time
#   face camera|normal   `camera` always faces you; `normal` lies flat on the
#                       surface it was spawned against -- that is a decal
#   dome 1              every particle at ONE speed over the hemisphere around
#                       the normal, so the front is an edge you can see rather
#                       than a smear. For anything whose RADIUS is a fact
#   disc 1              the dome's equator: one speed around the ring
#                       perpendicular to the normal. With `face normal` the
#                       quads lie in that plane too, so a disc spawned against
#                       a floor is a ring of light running out across it. The
#                       dome cannot do this -- half of it leaves the ground
#
# Every number is an integer. Unknown keywords are skipped rather than
# rejected, so a file written for a newer build still loads in an older one.
#
# Editing this file updates the running game (dev builds): the definitions are
# re-read and live particles are dropped, so a change is visible on the next
# shot rather than the next launch.
#
# 이 파일을 수정하면 실행 중인 게임에 반영됩니다(개발 빌드). 정의를 다시 읽고 살아 있는
# 입자는 버리므로, 변경 사항은 다음 실행이 아니라 다음 발사에서 확인됩니다.

# --- weapon impacts ---------------------------------------------------------

# Sparks off a wall. Additive so they read as light against dark stone, and
# fast with a wide spread so the burst looks like it came off the surface.
e spark
  count 7
  life 260
  size 11 1
  rgb 255 232 170
  rgb2 220 90 20         # white-hot, cooling to ember orange
  alpha 85 0
  speed 340 280
  spawn 6
  drag 150               # sparks lose speed fast; they are small and light
  spin 540
  gravity 420
  stretch 22             # a spark off stone leaves at 3.4 m/s and a square
                         # says it is sitting still. `drag 150` bleeds that off
                         # inside the life, so the streak is a streak at the
                         # start and a dot by the end, without a second layer
  blend add
  face camera

# The same event seen on flesh. Slower, heavier, and it falls -- blood arcs
# where sparks fly. Alpha-blended because it must be able to be darker than
# what is behind it, which additive can never be.
e blood
  count 9
  life 520
  size 10 3
  rgb 175 20 16
  rgb2 70 8 8            # darkens as it falls, the way blood does
  alpha 92 0
  speed 220 185
  spawn 9
  drag 60
  spin 260
  gravity 900
  blend alpha
  face camera

# The mark left behind. One particle, no motion, and a long life: this is a
# decal wearing a particle's clothes. `face normal` is what makes it lie on
# the wall instead of turning to follow the camera.
e bullethole
  count 1
  life 6000
  size 9 9
  rgb 12 10 9
  alpha 85 0
  speed 0 0
  gravity 0
  blend alpha
  face normal

# The mark a BOLT leaves, which is not the mark a bullet leaves. ioquake3 draws
# this distinction at the line where it picks its shader -- energyMarkShader
# for the plasma and the BFG, bulletMarkShader for the machinegun -- and the
# reason is the obvious one: a pellet takes a chip out of the stone and a bolt
# burns it. `bullethole` is nearly black and 9cm; this is wider, browner at the
# edge, and it does not have a hole in the middle of it.
#
# SHARED BY BOTH SIDES OF THE FIGHT, and that is a deliberate exception to the
# rule the rest of this file follows. `blastburst` and `boltburst` are two
# definitions because they are the same shape in opposite colours, and warm is
# yours while cold is theirs -- but that doctrine is about LIGHT. A scorch is
# the absence of light: it is what is left when a surface has stopped
# reflecting, and a burn tinted green so the player can tell whose bolt made it
# would be a claim the surface cannot carry. One definition, and the two call
# sites in proj.c and enemy.c name it together.
#
# *볼트*가 남기는 자국이며, 탄환이 남기는 자국이 아닙니다. ioquake3은 셰이더를 고르는 줄에서
# 이 구분을 긋습니다. 플라즈마와 BFG에는 energyMarkShader를, 기관총에는 bulletMarkShader를
# 씁니다. 이유는 뻔한 것입니다. 산탄은 돌을 쪼아 내고 볼트는 태웁니다. `bullethole`은 거의
# 검고 9cm입니다. 이것은 더 넓고 가장자리가 더 갈색이며, 가운데에 구멍이 없습니다.
#
# *싸움의 양쪽이 함께 씁니다.* 이 파일의 나머지가 따르는 규칙에 대한 의도적인 예외입니다.
# `blastburst`와 `boltburst`가 두 정의인 이유는 반대되는 색의 같은 형태이고, 따뜻한 것은 당신
# 것이며 차가운 것은 그들 것이기 때문입니다. 그러나 그 원칙은 *빛*에 대한 것입니다. 그을음은
# 빛의 부재입니다. 표면이 반사하기를 그만두었을 때 남는 것이며, 누구의 볼트가 만들었는지
# 플레이어가 알 수 있도록 녹색으로 물들인 화상은 그 표면이 감당할 수 없는 주장입니다. 정의
# 하나이고, proj.c와 enemy.c의 두 호출 지점이 함께 그 이름을 댑니다.
e scorch
  count 1
  life 4500
  size 15 15
  rgb 22 18 15           # burnt, not black: `bullethole` is the black one and
  rgb2 12 10 9           # two marks the same colour are one mark twice
  alpha 74 0
  speed 0 0
  gravity 0
  blend alpha
  face normal

# --- the player's bolt, landing ---------------------------------------------
#
# The rapid's impact was ONE LINE and the line was `spark` -- the shotgun's,
# authored warm for a lead pellet on stone. Every other thing this weapon puts
# on screen is green: the bolt is drawn in LIGHT_COL_BOLT, the wall it flies
# past is lit in it, and then it landed in orange. The palette's own rule in
# scene.c is that warm is yours and cold is theirs, and the bolt was managing
# to break it in the third direction.
#
# Two layers, because a hit has an instant and an aftermath. Xonotic splits the
# same event the same way -- `electro_impact` carries the core and the smoke,
# `electro_ballexplode` the sparks -- and Quake II's TE_BLASTER is
# CL_BlasterParticles with a light on top of it. The third and fourth layers
# are not here because they already exist: the scorch above, and `smokepuff`,
# which the shotgun wrote and a bolt has no reason to write again.
#
# 연사의 피탄은 *한 줄*이었고 그 줄은 `spark`, 즉 샷건의 것이었습니다. 납 산탄이 돌에 맞는
# 것을 위해 따뜻하게 작성된 것입니다. 이 무기가 화면에 내놓는 다른 모든 것은 녹색입니다.
# 볼트는 LIGHT_COL_BOLT로 그려지고 그것이 지나가는 벽도 그 색으로 밝혀지는데, 그러고 나서
# 주황색으로 착탄했습니다. scene.c에 있는 팔레트 자신의 규칙은 따뜻한 것이 당신 것이고 차가운
# 것이 그들 것이라는 건데, 이 볼트는 세 번째 방향으로 그것을 어기고 있었습니다.
#
# 두 겹인 이유는 피탄에 순간과 여파가 있기 때문입니다. Xonotic은 같은 사건을 같은 방식으로
# 나눕니다. `electro_impact`가 코어와 연기를 지니고 `electro_ballexplode`가 불꽃을 지닙니다.
# Quake II의 TE_BLASTER는 CL_BlasterParticles에 빛을 얹은 것입니다. 셋째와 넷째 겹이 이곳에
# 없는 이유는 이미 존재하기 때문입니다. 위의 그을음과, 샷건이 작성했으며 볼트가 다시 쓸 이유가
# 없는 `smokepuff`입니다.

# The instant. White with the green already in it rather than green going
# white: a core that opened in the bolt's own hue would be a small bolt sitting
# on the wall, where what happened is that one stopped existing. `blastflash`
# makes the same argument at ten times the size, and the small `spawn` is the
# same trick for the same reason -- these are MEANT to overlap and saturate.
# *순간*입니다. 녹색이 희어지는 것이 아니라 이미 녹색이 든 흰색입니다. 볼트 자신의 색조로
# 열리는 코어는 벽에 앉은 작은 볼트일 뿐이지만, 실제로 일어난 일은 그것이 존재하기를
# 그만두었다는 것입니다. `blastflash`가 열 배 크기로 같은 논지를 펴며, 작은 `spawn`도 같은
# 이유의 같은 수법입니다. 이들은 겹쳐서 포화하도록 *의도된* 것입니다.
e zapflash
  count 2
  life 80                # SHORTER AND SMALLER THAN IT LOOKS LIKE IT SHOULD BE.
  size 16 30             # `blastflash` is 132cm across and gets away with it
                         # because a grenade goes off once. This lands eleven
                         # times a second, and a half-metre white blob at that
                         # rate is not a series of hits, it is a strobe. Scale
                         # here is set by the FIRE RATE, not by the event
  rgb 236 255 232
  rgb2 96 255 128        # resolving INTO the bolt's green as it leaves
  alpha 96 0
  speed 25 18
  spawn 4                # small: they are MEANT to overlap
  drag 280               # collapses in place rather than travelling
  spin 220
  blend add
  face camera

# The aftermath: what came off the wall. Cools from near-white into
# LIGHT_COL_BOLT's acid green exactly the way `boltburst` cools into the
# monsters' blue -- the two are mirrored on purpose, which is the whole of why
# the rapid needed its own rather than borrowing that one.
# `gravity 120` is small and not zero. Plasma spatter is not debris and should
# not fall like it, but sparks that hang in a flat plane read as a decal that
# forgot to be one.
# *여파*이며, 벽에서 떨어져 나온 것입니다. `boltburst`가 몬스터의 파랑으로 식는 것과 똑같이
# 흰색에 가까운 데서 LIGHT_COL_BOLT의 강한 녹색으로 식습니다. 둘은 의도적으로 거울상이며,
# 연사가 그것을 빌리지 않고 자기 것을 필요로 한 이유 전부가 그것입니다.
# `gravity 120`은 작지만 0이 아닙니다. 플라즈마 비산물은 파편이 아니므로 그렇게 떨어져서는 안
# 되지만, 평평한 평면에 걸린 불꽃은 데칼이 되기를 잊은 데칼로 읽힙니다.
e zapburst
  count 10
  life 260
  size 9 2
  rgb 198 255 208
  rgb2 44 158 66
  alpha 88 0
  speed 380 320
  spawn 8
  drag 150
  spin 420
  gravity 120
  stretch 24
  blend add
  face camera

# The trail the same bolt leaves behind it in flight. One particle per emission
# and barely any speed: the bolt supplies the motion, so a trail that also
# moved would smear ahead of the thing it is supposed to be trailing. It hangs
# and fades where the bolt passed, which is what reads as a wake.
#
# Short-lived on purpose. The pool is shared across every effect, and a bolt
# emitting for two seconds of flight is the one thing here that can fill it on
# its own -- see the emission interval in enemy.c.
e bolttrail
  count 1
  life 280
  size 9 1
  rgb 150 200 255
  rgb2 40 80 170         # the wake cools behind the bolt
  alpha 65 0
  speed 12 8
  spawn 3
  drag 90
  spin 120
  gravity 0
  blend add
  face camera

# And the RIBBON, which is the half of a trail the layer above cannot be. That
# one is additive and 280ms: it is the bolt's heat, it sits where the bolt was
# and it is gone before the bolt has crossed the room. What a projectile
# actually leaves behind is longer than its own flight and WIDENS away from the
# head -- the wake is a cone, not a tube -- and it has to be able to be darker
# than the wall behind it, which nothing additive can ever be.
#
# Faint on purpose (28%). Thickness comes from many thin layers overlapping,
# the same argument `lavasmoke` makes: one puff every 30ms for a two-second
# flight is sixty of these, and at any opacity worth noticing that is a solid
# tube painted across the room.
#
# 그리고 *리본*이며, 위의 겹이 될 수 없는 궤적의 나머지 절반입니다. 그쪽은 가산이고
# 280ms입니다. 볼트의 열이고, 볼트가 있던 자리에 놓이며, 볼트가 방을 가로지르기 전에
# 사라집니다. 발사체가 실제로 뒤에 남기는 것은 자기 비행보다 오래가고 머리에서 멀어질수록
# *넓어집니다*(자취는 관이 아니라 원뿔입니다). 그리고 뒤의 벽보다 어두울 수 있어야 하는데,
# 가산인 것은 결코 그럴 수 없습니다.
#
# 의도적으로 흐립니다(28%). 두께는 얇은 겹이 여럿 겹쳐서 나오며, `lavasmoke`가 펴는 것과
# 같은 논지입니다. 2초 비행에 30ms마다 하나면 예순 장이고, 눈에 띌 만한 불투명도라면
# 그것은 방을 가로질러 칠한 단단한 관입니다.
e boltwake
  count 1
  life 620
  size 5 30              # 5cm at the head, 30cm where it has fallen behind
  rgb 122 152 205
  rgb2 40 48 70
  alpha 28 0
  speed 8 6
  spawn 2
  drag 140
  spin 30
  gravity -15            # drifts up as it dies, so the wake does not sag
  blend alpha
  face camera

# --- lava ---------------------------------------------------------------

# Smoke boiling off a lava floor. Spawned by main.c at points sampled across
# the hazard sectors, not by any impact -- see the lava smoke block there for
# why the sampling is what it is.
#
# NEGATIVE gravity is what makes it rise, and it is the whole effect: hot gas
# is buoyant, so it accelerates upward rather than merely being thrown that
# way. Launching it up with `speed` alone and letting it coast would slow to a
# stop and hang, which reads as steam in a vacuum. `speed` is kept low for the
# same reason -- the rise should come from the buoyancy, not the throw.
#
# `alpha` peaks low: this sits on top of a surface that is already the
# brightest thing in the room, and smoke opaque enough to be obvious hides the
# lava it is supposed to be coming from.
#
# `blend alpha`, NOT add: smoke is the one thing here that must be able to be
# DARKER than what is behind it. Additive smoke over lava glows, which is a
# contradiction -- it is soot.
#
# 용암 바닥에서 끓어오르는 연기입니다. 충돌이 아니라 main.c가 위험 지형 섹터 전체에서
# 표본 추출한 지점에 생성합니다. 표본 추출 방식의 이유는 그곳의 용암 연기 블록을
# 참조하십시오.
#
# *음수* 중력이 상승을 만들며 그것이 이 효과의 전부입니다. 뜨거운 기체는 부력을 받으므로
# 단지 위로 던져지는 것이 아니라 위로 가속합니다. `speed`만으로 쏘아 올려 관성으로
# 두면 점점 느려지다 멈춰 매달리는데, 이는 진공 속의 수증기처럼 읽힙니다. 같은 이유로
# `speed`를 낮게 유지합니다. 상승은 던지기가 아니라 부력에서 나와야 합니다.
#
# `alpha`의 정점이 낮습니다. 이것은 방에서 이미 가장 밝은 표면 위에 놓이며, 눈에 띌 만큼
# 불투명한 연기는 정작 그것이 피어오르는 용암을 가립니다.
#
# `blend add`가 아니라 `alpha`입니다. 연기는 이곳에서 뒤에 있는 것보다 *어두울* 수
# 있어야 하는 유일한 대상입니다. 용암 위의 가산 연기는 빛나게 되는데, 그것은 모순입니다.
# 그을음이기 때문입니다.
e lavasmoke
  count 1                # one puff per spawn -- world.c paces the rate
  life 4200              # LONG. Density here is accumulation: a puff has to
                         # still be in the air when the next several arrive, or
                         # the room never fills and each puff reads on its own.
  size 34 150            # and it has to get BIG. Coverage per draw call is the
                         # cheap half of "thick" -- every particle is its own
                         # draw call (see fx.c), so widening one costs nothing
                         # where adding one costs a call.
  rgb 96 74 62           # warm soot, lit from below by what it came off
  rgb2 44 42 46          # cooling to a neutral grey as it climbs
  alpha 26 0             # FAINTER than before, deliberately. Thickness should
                         # come from many thin layers overlapping, not from a
                         # few opaque ones -- opaque puffs read as blobs
                         # crossing each other, thin ones read as air.
  speed 45 26            # gentler still: it should hang, not travel
  spawn 26               # scattered, so a run of puffs is not a column
  drag 70                # bleeds the initial push off sooner, so it stalls and
                         # spreads instead of climbing out of the room

# --- what the lava is doing, as opposed to what it is giving off -------------
#
# THE SMOKE ABOVE ALREADY SAYS "HOT". It does not say LIQUID -- smoke rises off
# a fire, a corpse and a wrecked machine just as readily, and a sea of it reads
# as a burning floor rather than as something you would sink into. What says
# liquid is a surface that BREAKS: a bubble swells at one point, holds, and
# goes, and the eye reads depth and motion from the fact that the surface had
# to open to let it out.
#
# So this is deliberately the opposite of `lavasmoke` in every parameter that
# matters. Smoke is long, big, faint, grey, and climbs out of frame. A boil is
# SHORT, small, bright, orange, and never leaves the surface it came from --
# the whole event happens within half a metre of the lava.
#
# ADDITIVE AND HOT, where the smoke is alpha and cool. A bubble is the lava's
# own interior seen through a thin skin, so it is brighter than the crust
# around it, and additive is the only blend that can say brighter.
e lavaboil
  count 1                # one at a time; world.c paces them like the smoke
  life 620               # SHORT. A bubble that lingers is a floating ball --
                         # what makes it read as a bubble is that it goes
  size 7 26              # GROWS, which is the whole gesture: it swells and
                         # bursts. Every other particle in this file shrinks,
                         # and the two directions are what separates a thing
                         # that is dissipating from a thing that is building
  rgb 255 214 96         # the interior: hotter and yellower than the crust
  rgb2 226 96 24         # cooling to the surface colour as it opens
  alpha 85 0             # bright at birth, gone at the burst -- not a fade so
                         # much as the skin finally letting go
  speed 16 12            # barely rises. It is not thrown, it is surfacing
  spawn 4                # nearly a point: a bubble is ONE hole in the surface
  drag 82                # kills the rise almost at once, so it swells in place
  spin 0                 # a bubble does not tumble; only the random start angle
  gravity -8             # a whisper of lift, enough to clear its own hole
  blend add              # brighter than the lava, never darker
  face camera

# above it is additive: the dome, the core and the flash are light, and light
# added to a frame can only ever brighten it. So the blast had two states and

#

# ramp does the work on its own -- born hot orange, dead the colour of soot --

# thrown; it does not fly. High drag with a modest speed puts the puffs where

# --- the altar --------------------------------------------------------------
#
# WHAT AN ALTAR IS FOR. A wave reward thrown at the player's feet is collected
# without a decision -- you are already standing on it. loot.txt can throw it
# somewhere else instead, and the moment it does, the drop point has a problem
# the old one never had: it is across the room, and nothing about the room says
# which part of it is the one you were paid at. Six seconds of breather is not
# long enough to search.
#
# So the spot announces itself, in three layers, for the same reason the blast
# is four: each answers a different question. WHERE (the ring, running out
# across the floor at the instant the wave ends -- motion at the edge of vision
# is what turns the head), WHAT (the core, a warm column that says shrine and
# not explosion), and STILL HERE (the motes, paced by world.c for as long as
# the shrine burns, because the ring and the core are over in half a second and
# the player has six).
#
# Warm gold throughout, and deliberately not the blue every other bright thing
# in this game is. A bolt is blue, the hook is blue, a caster's burst cools into
# blue -- all of them things that are about to hurt. The one thing in the room
# that is a REWARD should not be drawn in the colour of the things that are not.
#

#
# 그래서 그 자리가 스스로를 알리며, 폭발이 네 겹인 것과 같은 이유로 세 겹입니다. 각 겹이

# 시야 가장자리의 움직임이 고개를 돌리게 합니다), *무엇인가*(폭발이 아니라 제단이라고
# 말하는 따뜻한 기둥인 코어), 그리고 *아직 여기 있다*(제단이 타오르는 동안 world.c가

#
# 전체가 따뜻한 금색이며, 이 게임의 다른 모든 밝은 것이 쓰는 파랑이 의도적으로 아닙니다.
# 볼트가 파랗고, 갈고리가 파랗고, 캐스터의 폭발이 파랑으로 식습니다. 전부 곧 아프게 할
# 것들입니다. 방에서 유일하게 *보상*인 것이 그렇지 않은 것들의 색으로 그려져서는 안 됩니다.

# WHERE. Speed x life = 300cm, so the ring stops three metres out -- far enough
# to be seen past whatever is between you and it, near enough that it does not
# read as something happening to the whole room. `face normal` is what keeps it
# lying on the floor; without it this is a vertical hoop.
e altarring
  count 26
  life 900
  size 26 6
  rgb 255 226 150
  rgb2 210 130 30
  alpha 80 0
  speed 333 0            # TWO values, always: `speed` reads a pair, and one
                         # number leaves the whole line unassigned -- a ring
                         # that spawns, lives out its 900ms and never moves
  disc 1
  spin 0
  gravity 0
  blend add
  face normal

# WHAT. Slow, large, and it rises: a column, not a burst. The low speed is the

# --- what a floor item gives off --------------------------------------------
#
# WHAT THIS REPLACED, and why the replacement is smaller. A floor item used to
# carry an additive halo drawn behind its sprite plus a dynamic light while it
# was fresh. Both worked -- the item was visible from the far end of a hall --
# and both were the wrong kind of visible: a glowing disc standing in the air
# is a LAMP, and this game already spends that language on the things that are
# about to hurt you. A bolt glows. The hook glows. A muzzle glows. An item that
# glows the same way is asking to be read as one of those, and it does it
# while parked, forever, which none of them do.
#
# Motes rising off it say the same thing with none of that. They are small, so
# nothing reads as a light source; they MOVE, which is what actually catches
# the eye at distance -- a static glow competes with every lit surface in the
# room, and drifting specks compete with nothing; and they leave the item's own
# drawing completely untouched, so what says WHICH item this is is never sitting
# inside what says WHERE it is.
#
# 무엇을 대체했으며, 왜 대체물이 더 작은가. 바닥 아이템은 스프라이트 뒤에 그려지는 가산
# 헤일로와, 갓 도착했을 때의 동적 광원을 지니고 있었습니다. 둘 다 동작했고(복도 저편에서도
# 아이템이 보였습니다) 둘 다 잘못된 종류의 보임이었습니다. 공중에 서 있는 빛나는 원반은
# *등*이며, 이 게임은 그 언어를 이미 당신을 아프게 할 것들에 쓰고 있습니다. 볼트가
# 빛납니다. 갈고리가 빛납니다. 총구가 빛납니다. 같은 방식으로 빛나는 아이템은 그것들 중
# 하나로 읽히기를 청하는 것이며, 게다가 세워진 채로 영원히 그럽니다. 그중 무엇도 그러지
# 않습니다.
#
# 아이템에서 피어오르는 티끌은 그것 없이 같은 말을 합니다. 작아서 광원으로 읽히는 것이
# 없고, *움직이므로* 멀리서 실제로 눈길을 끕니다(정적인 발광은 방의 모든 밝은 표면과
# 경쟁하지만 떠다니는 알갱이는 무엇과도 경쟁하지 않습니다). 그리고 아이템 자신의 그림을
# 전혀 건드리지 않으므로, *어느* 아이템인지 말해 주는 것이 *어디에* 있는지 말해 주는 것
# 안에 갇히는 일이 없습니다.

# One mote per spawn; pickup.c paces the rate for every item on the floor, the
# same arrangement lavasmoke has with world.c. NEGATIVE gravity is the whole
# effect: the rise has to come from buoyancy rather than from a throw, or the
# specks slow to a stop at the top of their arc and hang there, which reads as
# dust in a jar. `speed` stays low for the same reason.
#
# Pale green, which is the colour `pickup` fades to when one is collected --
# so the mark an item leaves in the air and the burst it makes when taken are
# the same colour, and a player who has picked up one thing has already been
# taught what these specks mean.
#
# 생성당 티끌 하나이며, 바닥의 모든 아이템에 대해 pickup.c가 빈도를 조절합니다. lavasmoke가
# world.c와 맺는 것과 같은 배치입니다. *음수* 중력이 이 효과의 전부입니다. 상승은 던지기가
# 아니라 부력에서 나와야 하며, 그러지 않으면 알갱이가 포물선 꼭대기에서 멈춰 매달리는데
# 그것은 병 속의 먼지로 읽힙니다. 같은 이유로 `speed`는 낮게 유지합니다.
#
# 옅은 초록이며, 아이템을 획득했을 때 `pickup`이 사그라드는 색입니다. 아이템이 공중에
# 남기는 표식과 획득될 때 내는 폭발이 같은 색이 되므로, 하나라도 주워 본 플레이어는 이
# 알갱이들이 무엇을 뜻하는지 이미 배운 셈입니다.
e itemmote
  count 1
  life 1500
  size 5 1               # SMALL. A mote that reads as a shape is a lamp again
  rgb 200 255 226
  rgb2 80 195 145
  alpha 62 0
  speed 44 22            # barely a push; the rise is the gravity's job
  spawn 16               # scattered across the item, not a single thread
  drag 30
  spin 70
  gravity -95            # negative: it climbs, and keeps climbing
  blend add
  face camera

# The item's own arrival. Smaller and slower than it was, because the motes now
# carry the "there is something here" half and this only has to carry "and it
# just got here" -- a burst loud enough to do both was doing one of them twice.
# It rises for the same reason they do, so the two read as one event rather
# than as a burst followed by an unrelated trickle.
#
# 아이템 자신의 도착입니다. 예전보다 작고 느립니다. 이제 "여기 무언가 있다"는 절반을
# 티끌이 나르므로, 이것은 "그리고 방금 도착했다"만 나르면 됩니다. 둘 다 할 만큼 큰 폭발은
# 그중 하나를 두 번 하고 있던 것입니다. 티끌과 같은 이유로 떠오르므로, 둘은 폭발과 뒤이은
# 무관한 흐름이 아니라 하나의 사건으로 읽힙니다.
e itemland

# A shot that did not land. The maw takes no damage while a single ward
# stands, and enemy.c withholds the hit flash for it deliberately -- the flash
# is how this game says "you are hurting it", and a boss that flashes while its
# health bar correctly refuses to move reads as a broken bar rather than as an
# invulnerable enemy.
#
# So this is the sentence the flash is not allowed to say. It has to read as a
# REFUSAL at a glance and from any range: cold where blood is warm, thrown back
# toward the shooter rather than away, and gone in a fifth of a second so it
# cannot be mistaken for something burning. `blend add` over a dark body makes
# it a flare on the surface instead of a stain in it.
#
# 닿지 않은 사격입니다. 결계핵이 하나라도 서 있는 동안 아귀는 피해를 받지 않으며, enemy.c는
# 그에 대해 피격 섬광을 의도적으로 억제합니다. 섬광은 이 게임이 "네가 그것을 아프게 하고
# 있다"고 말하는 방식이고, 체력바가 (올바르게) 움직이기를 거부하는데 섬광만 번쩍이는 보스는
# 무적인 적이 아니라 고장 난 바로 읽힙니다.
#
# 그래서 이것은 섬광이 말해서는 안 되는 그 문장입니다. 어느 거리에서든 한눈에 *거절*로
# 읽혀야 합니다. 피가 따뜻한 곳에서 차갑고, 바깥이 아니라 쏜 쪽으로 튕겨 나가며, 타는 것으로
# 오인될 수 없도록 5분의 1초 만에 사라집니다. 어두운 몸통 위의 `blend add`는 이것을 표면에
# 남는 얼룩이 아니라 표면 위의 섬광으로 만듭니다.
e warded
  count 10
  life 200
  size 9 2
  rgb 190 225 255
  rgb2 60 110 200        # cold, and it cools further -- nothing here is burning
  alpha 95 0
  speed 300 260
  spawn 5
  drag 420               # stops almost at once: it was stopped, not deflected far
  spin 700
  gravity 0              # no fall; this is a surface refusing, not a thing shed
  blend add
  face camera
