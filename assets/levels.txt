# SFPS level library -- edit freely, the dev build reloads this on save.
#
# Easiest way to edit this: build\mapedit.exe <level>. Draw sectors in the
# plan view, fly the 3D view to check them, CTRL+S. Editing by hand works too.
#
# A sector is a 2D floor plan polygon plus a floor and ceiling height; walls
# are vertical. Coordinates are 1/100 units (cm), so 1600 is 16 metres.
#
#   l <name>              begin a level
#   start <x> <z> <yaw>   player spawn, yaw in millidegrees
#   s                     begin a sector
#   floor <n>  ceil <n>   heights
#   hurt <dps>            damage per second to anything standing on this floor
#   mat floor|wall|ceil <name> ...   materials, from assets/textures.txt
#   p <x z> ...           the floor plan, read until the next word
#   next <name>           level the `exit` entity leads to
#   e <kind> <x> <z>      an entity
#
# Entity kinds: water_spirit/brute/caster spawn monsters -- the retired names
# "spawn", "imp" and "hound" still resolve, so a level written before those rows
# left enemy.c still fills. ammo/health are pickups, and `exit` ends the level --
# walk onto it and the game loads `next`, carrying your health and ammo across.
# A level with no `next` is the end of the game: its exit shows the win screen
# instead.
#
# A FLYER PLACED HERE STANDS ON THE FLOOR. `e` carries x and z and no height --
# a sector level has one floor per point on the plan, so Entity::y is 0 and
# make_monster only keeps a spawn height that is ABOVE the floor it found. The
# caster carries MON_FLIES and is the one kind that notices: place one in a
# sector level and you get a caster that hovers at ankle height. Levels that
# want the air are .map files, where the marker's origin carries its Z.
#
# 이곳에 놓인 비행체는 바닥에 섭니다. `e`는 x와 z를 나르고 높이는 나르지 않습니다. 섹터
# 레벨은 평면상의 한 점에 바닥이 하나이므로 Entity::y는 0이고, make_monster는 찾아낸 바닥보다
# *위*인 생성 높이만 유지합니다. 캐스터가 MON_FLIES를 지니며 이를 알아채는 유일한 종류입니다.
# 섹터 레벨에 하나 놓으면 발목 높이에서 정지 비행하는 캐스터를 얻습니다. 공중을 원하는 레벨은
# .map 파일이며, 그곳에서는 표식의 원점이 자기 Z를 나릅니다.
#
# `hurt` is charged only while GROUNDED, so a lava channel is something to jump
# or grapple across rather than a wall. It is independent of the floor material
# on purpose: retexturing a pit must not silently make it safe, and a level may
# want the lava material as decoration or an innocuous floor that kills.
# Because last-wins applies here too, a safe platform laid over a lava sector
# is safe to stand on -- which is what makes a lava room playable.
#
# `hurt`는 *지면에 있을 때만* 적용되므로, 용암 수로는 벽이 아니라 뛰어넘거나 훅으로
# 건너는 대상입니다. 바닥 재질과 독립적인 것은 의도적입니다. 구덩이의 텍스처를 바꾸는 것이
# 조용히 그곳을 안전하게 만들어서는 안 되며, 레벨이 용암 재질을 장식으로 쓰거나 멀쩡해
# 보이는 바닥을 치명적으로 만들고 싶을 수도 있습니다. 이곳에도 마지막 선언 우선 규칙이
# 적용되므로, 용암 섹터 위에 놓인 안전한 발판은 밟고 설 수 있습니다. 그것이 용암 방을
# 플레이 가능하게 만듭니다.
#
# SECTORS MAY OVERLAP, and the LAST one declared wins at any point. Doom tiles
# the plane and defines edges with linedefs, which is fiddly to author; here a
# platform inside a room is just a small sector laid on top of the big one, and
# no polygon has to be cut to make room for it. Last-wins rather than
# highest-floor-wins, because the latter makes a pit impossible: the room's
# floor would always beat the lower one dug into it.
#
# Walls are generated per edge: where another sector lies just outside, only
# the difference in floor and ceiling height is solid -- that is what makes a
# shared boundary a step you can walk over rather than a wall.

# Point lights: light <x> <y> <z> <radius> <r> <g> <b> <power>
#
# NO LEVEL DECLARES ONE ANY MORE, and the four that used to sit here are why
# the line is still documented. The parser reads `light`, ::Level keeps room
# for sixty-four of them, and nothing lights anything with them -- so a lamp
# written here is eight numbers that load and then sit still.
#
# WHAT HAPPENED TO THEM. A lamp was applied two ways and neither one looked
# right on the maps this game ships:
#
#   - COMPILED INTO THE VERTICES, it was sampled at the corners of each face
#     and smeared across everything between them. On a brush level whose walls
#     are single faces metres across, that is a gradient down one side of a
#     room, not a pool of light.
#   - HANDED TO THE SHADER EVERY FRAME, the pools came out round, but only the
#     eight nearest fit -- so a big room re-lit itself as you walked through
#     it, and nothing cast a shadow.
#
# So the rooms are lit by the engine's own ambient level plus the things you
# and the monsters put in the air: muzzle flashes, grenades, plasma, bolts.
# Bright ROOMS are a shader constant (AMBIENT in src/render.c); bright MOMENTS
# are what gets fired. src/scene.c's note above MoveLight is the whole account.
#
# The syntax stays documented rather than deleted because the parser still
# accepts it and a format that silently drops a word it can read is worse than
# one that reads a word nothing uses. If lamps ever come back, this is the line
# they come back as.
#
# *이제 어떤 레벨도 이것을 선언하지 않으며*, 이곳에 있던 네 개가 이 줄이 여전히 문서화되어
# 있는 이유입니다. 파서는 `light`를 읽고 ::Level은 예순넷을 담을 자리를 두지만, 그것으로
# 무엇을 밝히는 것은 없습니다. 그러므로 이곳에 적은 등은 로드된 뒤 가만히 있는 숫자 여덟
# 개입니다.
#
# *그것들에게 무슨 일이 있었는가.* 등은 두 가지 방식으로 적용되었고 이 게임이 출하하는
# 맵에서는 어느 쪽도 옳아 보이지 않았습니다.
#
#   - *정점에 구워지면* 각 면의 모서리에서 표본추출되어 그 사이 전부로 번졌습니다. 벽 하나가
#     몇 미터짜리 단일 면인 브러시 레벨에서 그것은 빛 웅덩이가 아니라 방 한쪽을 따라 흐르는
#     그러데이션입니다.
#   - *매 프레임 셰이더에 건네지면* 웅덩이는 둥글게 나왔지만 가장 가까운 여덟 개만 들어갔고,
#     그래서 큰 방은 걸어 다니는 동안 스스로를 다시 밝혔으며 아무것도 그림자를 드리우지
#     않았습니다.
#
# 그래서 방은 엔진 자신의 주변광에, 당신과 몬스터가 공중에 띄우는 것들(총구 섬광, 유탄,
# 플라즈마, 볼트)이 더해져 밝혀집니다. 밝은 *방*은 셰이더 상수(src/render.c의 AMBIENT)이고,
# 밝은 *순간*은 발사되는 것입니다. 전체 경위는 src/scene.c의 MoveLight 위 설명에 있습니다.
#
# 문법을 지우지 않고 문서로 남기는 이유는 파서가 여전히 이것을 받아들이기 때문이며, 읽을 수
# 있는 단어를 조용히 버리는 형식은 아무도 쓰지 않는 단어를 읽는 형식보다 나쁩니다. 등이 언젠가
# 돌아온다면, 돌아올 자리가 이 줄입니다.

# A lava moat, sunk into the room. Declared BEFORE the dais so the dais wins
# where they overlap -- last-wins is what lets the safe platform sit in the
# middle of the hazard without cutting either polygon.
#
# 20 dps is five seconds of standing in it from full health: long enough to
# cross deliberately and take the hit, short enough that lingering is a real
# mistake. The floor is dropped 40cm so it reads as a pit rather than as a
# painted-on texture, and the step back out is inside PLAYER_STEP so falling in
# is recoverable.
#
# 방에 파인 용암 해자입니다. 겹치는 곳에서 단상이 이기도록 단상보다 *먼저* 선언합니다.
# 마지막 선언 우선 규칙 덕분에, 어느 다각형도 잘라 내지 않고 위험 지형 한가운데에 안전한
# 발판을 둘 수 있습니다.
#
# 초당 20이면 만체력에서 5초간 서 있을 수 있습니다. 의도적으로 건너며 피해를 감수하기에는
# 충분히 길고, 머무는 것이 실제 실수가 될 만큼은 짧습니다. 바닥을 40cm 낮춰 덧칠한
# 텍스처가 아니라 구덩이로 읽히게 했고, 다시 올라오는 단차는 PLAYER_STEP 안에 있으므로
