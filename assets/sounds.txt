# SFPS sound library -- edit freely, the dev build reloads this on save.
#
# A SOUND IS A RECIPE OR A SAMPLE, whichever exists for its name.
#
# What is here is the recipes: a handful of integers describing how to
# synthesise a sound, which the mixer turns into a waveform as it plays. Same
# idea as the texture recipes -- keep the instructions, not the result.
#
# Freedoom's recordings sit alongside them in assets/sounds/, and bake.ps1
# turns those into 4-bit ADPCM and appends them AFTER these recipes, so a name
# that has both ends up with the sample. Deleting the WAV brings the recipe
# straight back, which is the same bargain the drawn sprites strike with the
# generated creatures.
#
# Three of these have no sample and never will: Doom has no pump-action rack,
# no grapple and no reel, so `pump`, `hook` and `hreel` are synthesised for
# good. That is why both kinds exist rather than one replacing the other.
#
# 사운드는 이름에 대해 존재하는 쪽에 따라 레시피이거나 샘플입니다. 이 파일에 있는 것은
# 레시피이며, Freedoom의 녹음은 assets/sounds/에 함께 있습니다. bake.ps1이 그것을 4비트
# ADPCM으로 바꿔 이 레시피들 *뒤에* 붙이므로, 둘 다 가진 이름은 샘플을 갖게 됩니다.
# WAV를 지우면 레시피가 곧바로 돌아옵니다. Doom에는 펌프 장전도, 갈고리도, 릴도 없으므로
# `pump`, `hook`, `hreel`은 영영 합성으로 남습니다.
#
# Grammar (integers only, as everywhere else in this project):
#   s <name>                              begin a sound
#   l <wave> <ms> <f0> <f1> <atk> <dec> <vol>    add one layer
#
#   wave  0 square   1 saw   2 sine   3 noise
#   ms    how long this layer lasts
#   f0    starting frequency in Hz   (ignored by noise)
#   f1    ending frequency in Hz     -- the sweep is what gives a shot its
#                                       "pew" and an impact its "thud"
#   atk   attack in ms, from silence to full
#   dec   decay in ms, back to silence
#   vol   0-100
#
# Layers of one sound play together. Real weapon sounds are almost never a
# single oscillator: a shotgun is a noise burst for the crack plus a low
# square for the body, and leaving either one out sounds like a toy.

s shot
l 3 320 1400   60   0 300  90     # noise crack, falling fast
l 0 200  150   40   2 190  55     # low square body
l 1  90  420  110   0  90  35     # short saw bite up front

s impact
l 3 130  900  120   0 120  55     # short gritty tick
l 0  70  260   70   0  70  30     # small thump underneath

s pump
l 3  90 2200  700   0  85  40     # mechanical rasp
l 0  60  520  180   2  55  25

l 3 110  700  200   0 100  45     # claw-swish noise

s epain

l 3  70  900  300   0  70  35

s edie

l 0 300  120   45  10 280  45     # low body
l 3 260  500  120   0 240  35     # rattle

# --- the spawn portal ------------------------------------------------------
#
# TWO SOUNDS, AND THE PAIR IS THE POINT. `spawnwarn` sweeps UP and `spawnpop`
# sweeps DOWN through the same register, so the second reads as the first
# resolving rather than as a separate noise. That inversion is the only thing
# telling the player the portal FINISHED rather than merely stopped, and it is
# the same trick `pdie` and `win` use on each other.
#
# The warning is the one sound in this file that promises rather than reports.
# Everything else fires because something already happened; this fires 0.55s
# BEFORE it does (SPAWN_WARN_TIME), and it has to survive being heard from
# behind while the player is busy. Hence the long attack: a swell is audible in
# peripheral hearing where a transient is not, and it cannot be mistaken for a
# gunshot somewhere off screen.
#
# Both are deliberately quieter than the weapons. Up to ENEMY_MAX_SPAWNERS of
# these can be in flight at once and the mixer has twelve voices; a portal that
# fought the shotgun for level would win an argument it should not be having.
#
# 소리는 둘이며, 그 *짝*이 핵심입니다. `spawnwarn`은 위로, `spawnpop`은 같은 음역을 타고
# 아래로 쓸어내립니다. 그래서 두 번째 소리가 별개의 소음이 아니라 첫 번째의 *해결*로
# 읽힙니다. 이 반전만이 플레이어에게 포탈이 그냥 멈춘 것이 아니라 *완결되었음*을 말해 주며,
# `pdie`와 `win`이 서로에게 쓰는 것과 같은 기법입니다.
#
# 예고음은 이 파일에서 보고가 아니라 *약속*을 하는 유일한 소리입니다. 다른 모든 것은 이미
# 무슨 일이 일어났기 때문에 울립니다. 이것은 그 일이 일어나기 0.55초 *전에*(SPAWN_WARN_TIME)
# 울리며, 플레이어가 다른 일에 매여 있는 동안 등 뒤에서 들려도 살아남아야 합니다. 그래서 어택이
# 깁니다. 부풀어 오르는 소리는 주변 청각에 걸리지만 순간음은 그렇지 않으며, 화면 밖 어딘가의
# 총성으로 오해될 수도 없습니다.
#
# 둘 다 무기보다 의도적으로 조용합니다. 이것이 최대 ENEMY_MAX_SPAWNERS개까지 동시에 떠 있을 수
# 있는데 믹서의 보이스는 열둘입니다. 샷건과 음량을 다투는 포탈은 해서는 안 될 논쟁에서 이기는
# 셈입니다.

s spawnwarn
l 2 520  90  360  140 380  62    # sine swelling upward -- the charge building
l 1 460  45  180   90 360  38    # saw underneath for body, an octave down
l 3 300 700  260  120 180  22    # a breath of noise: the energy, not an impact

s spawnpop
l 3 260 1800 240    0 240  78    # the crack of arrival, falling fast
l 0 220  900 110     0 200  60    # square sweeping DOWN -- the warning inverted
l 2 300  240  60     8 280  52    # low sine settling: the thing has body now

# --- pickups and the empty gun ------------------------------------------

s pammo
l 0 90  520  760   0  85  55     # a bright mechanical clack, rising
l 1 70  900 1300   0  65  30

s pmed
l 2 220 660  990   4 210  55     # a warm ascending chime
l 2 180 990 1320  10 170  40

# AN ARTIFACT IS NOT A SHELL BOX. Both were pammo until the three powerups were
# written, which made a thirty-second window sound exactly like topping up ammo
# -- and this file already differentiates, pmed being its own chime. Long, rising
# and harmonically thicker than either: the pickup that changes the next half
# minute should be the one the player hears from across the room.
s part
l 2 320 330  990   8 300  60     # the swell -- a fifth and an octave up
l 2 300 494 1480  40 280  38     # a fifth above that, entering late
l 1 180 165  330  12 170  22     # a saw body, so it is not a pure tone

s dry
l 0 40  180  150   0  38  45     # a small dead click, no body
l 3 30  600  300   0  28  25

# --- level exit ----------------------------------------------------------

s exit
l 1 320 300 1400   4 300  70    # a rising saw sweep -- you made it out
l 2 260 700 1600   8 240  45    # a sine over it for a chime
l 3 120 900  400   0 110  30    # a short zap

# --- game over, and game won -----------------------------------------------

# The player's death. Deliberately the inverse of `win` below: where that
# rises through three notes and resolves upward, this falls and never lands on
# anything. The two endings should be distinguishable with the screen off.
#
# Longer than every other sound here (900ms) because it is the only one nothing
# can interrupt -- the world is frozen behind it.
#
# 플레이어의 사망입니다. 아래의 `win`과 의도적으로 정반대입니다. 그쪽이 세 음을 거쳐
# 위로 해결되는 반면 이쪽은 하강하며 어디에도 안착하지 않습니다. 두 결말은 화면을 꺼도
# 구분되어야 합니다.
#
# 이곳의 다른 모든 소리보다 긴 900ms인데, 무엇도 이를 중단시킬 수 없는 유일한 소리이기
# 때문입니다. 뒤에서 월드가 정지해 있습니다.
s pdie
l 2 900 330  70    6 880  70     # a long sine fall, all the way down
l 0 700 160  40   10 680  50     # a square body sagging under it
l 3 420 500  90    0 400  40     # the breath going out

s win
l 2 260 440  660   4 240  60     # a rising sine fanfare, first note
l 2 300 660  990   8 280  65     # second note, a fifth up
l 2 460 990 1320  14 440  60     # third, resolving up an octave
l 0 700 220  110   0 650  20     # a long warm pad underneath

# --- the caster ------------------------------------------------------------
# Cold and tonal where the melee monsters are all growl and noise, so the sound
# of a bolt being readied is distinguishable from a claw swipe without looking.

s ecast
l 2 380 180  880   8 360  65     # a rising sine whine -- the wind-up you dodge
l 1 260 440 1320  20 240  40     # a saw over it for bite
l 3 120 300  900   0 110  25     # a breath of noise as it releases

s ehit
l 3 140 1200 260   0 130  60     # the bolt bursting
l 2 180  660 180   0 170  45     # a low tonal thump under it

# --- the grapple hook -------------------------------------------------------
# Four beats, four sounds, because the player has to be able to tell them apart
# without looking: the throw leaves, the claw bites something, the winch reels,
# and the arrival throws you off. An earlier version had only the throw and
# borrowed `impact`/`ehit` for the rest, which meant a hook landing on a wall
# was indistinguishable from a shotgun pellet doing the same.

s hook
l 0 55  2400  650   0  50  55     # a fast metallic snap -- the claw leaving
l 3 45  1600  300   0  40  35     # a scrape of noise riding it

# The claw biting STONE. Hard, bright, over instantly -- metal on rock. This is
# the sound that used to be the tail of `hook`, split out now that the flight
# has a real duration and the bite lands whenever it lands.
s hbite
l 0 70   900  220   0  65  55     # the clunk of the claw seating
l 3 60  2200  600   0  55  40     # a chip of stone coming off
l 0 110  150   90   4 100  35     # a low body under it, so it has weight

# The claw biting FLESH. Duller and lower with no bright chip: meat does not
# ring. Same length so the two read as the same event on different materials
# rather than as two different mechanics.
s hbiteb
l 3 90   420  110   0  85  60     # a wet thud
l 0 130  120   70   6 120  45     # a low body, longer than the stone version
l 2 70   260  140   0  65  25     # a soft tonal edge so it is not just noise

# The winch, reeling. The only LOOPING sound in the game: it is retriggered
# while HOOK_PULLING and must therefore be short enough to restart cleanly and
# quiet enough to sit under everything else. A rising sweep sells acceleration
# without needing to know the actual speed.
s hreel
l 1 110  180  340   6 100  32     # a saw rising -- the winch spinning up
l 3 90   600  900   0  85  18     # chain noise over it, deliberately faint

# Arrival: the launch that throws the player off. Bigger than the bite, with a
# downward sweep that reads as a shove rather than an impact -- this is the
# beat where the player stops being pulled and starts flying.
s hland
l 0 90   320   90   0  85  60     # a heavy thump
l 3 140 1400  200   0 130  45     # the burst of the release
l 2 220  180   60   8 210  40     # a low tail so the launch has follow-through

# --- the boss opening and closing ---------------------------------------
#
# TWO SOUNDS, AND THE PAIR IS THE POINT, exactly as `spawnwarn` and `spawnpop`
# are a pair: `bossopen` sweeps UP through a register and `bossward` sweeps
# DOWN through the same one, so the second reads as the first being undone
# rather than as an unrelated noise.
#
# THIS PAIR EXISTS BECAUSE THE BOSS CANNOT BE SEEN WHEN IT MATTERS. The maw is
# anchored to a wall and the wards are scattered around the room, so the player
# is by construction looking AWAY from it at the moment the last ward falls --
# that is the whole design of the fight. A groggy window opened silently is a
# window the player finds late, and there are only three of them.
#
# Louder than the portal pair and deliberately so. Those are "a thing to notice,
# not a thing to react to yet", and there may be eight of them at once. There is
# exactly one of these and it is the most important thing in the room.
#
# 한국어
# ------
# 두 소리이며 그 쌍이 요점입니다. `spawnwarn`과 `spawnpop`이 쌍인 것과 정확히 같습니다.
# `bossopen`은 한 음역을 타고 *올라가고* `bossward`는 같은 음역을 타고 *내려가므로*, 두 번째가
# 무관한 소음이 아니라 첫 번째가 되돌려지는 것으로 읽힙니다.
#
# 이 쌍이 존재하는 이유는 정작 중요한 순간에 보스를 볼 수 없기 때문입니다. 아귀는 벽에 고정되어
# 있고 결계핵은 방 곳곳에 흩어져 있으므로, 마지막 결계핵이 쓰러지는 순간 플레이어는 구조적으로
# 그것을 등지고 있습니다. 그것이 이 전투의 설계 전부입니다. 조용히 열린 그로기 창은 플레이어가
# 늦게 발견하는 창이고, 그런 창은 셋뿐입니다.
#
# 포탈 쌍보다 크며 의도적입니다. 그쪽은 "반응할 것이 아니라 알아챌 것"이고 한 번에 여덟 개까지
# 있을 수 있습니다. 이쪽은 정확히 하나이며 방에서 가장 중요한 것입니다.

s bossopen
l 2  90 1100  260   40  900  96    # sine climbing far -- something very large opening
l 1  70  520  140   35  760  70    # saw an octave down, for the mass behind it
l 3 180 1400  120    0  420  54    # noise breath: air moving, not an impact

s bossward
l 2 260  900   90 1100  900  92    # the same climb, run backwards
l 1 140  760   70  520  760  68    # and its saw, likewise
l 0 120  260   40  200  520  46    # square settling low: the thing has shut
