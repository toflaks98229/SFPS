# SFPS -- the three things the game says outside the fight.
#
# GRAMMAR
#   c <name>   opens a cutscene. The names this build knows are `intro`,
#              `victory` and `defeat`; anything else is parsed and discarded,
#              so a file written for a later build still plays here.
#   p          opens a page. A page is one screen, held until it times out or
#              the player presses something.
#   t "..."    one line of text on the open page. Up to four per page.
#   hold <ms>  how long the open page waits before advancing by itself.
#              Default 4500. Clamped up to 600, because a page that expires on
#              the frame it starts reads as a rendering fault.
#
# THREE RULES THE FORMAT IMPOSES, and each is the font's, the screen's or the
# bake's rather than a preference:
#
#   MIND THE WIDTH, NOT THE LENGTH. A line may be as wide as STORY_LINE_W --
#   282 glyph pixels, which is 35 Hangul syllables or 47 Latin letters -- and
#   tools/storytest.c measures every line in this file against it. Going over
#   fails a build rather than clipping a sentence in a cutscene. The buffer
#   (STORY_LINE_MAX) is 112 bytes and will not be what stops you: a syllable
#   costs three of those and eight of the pixels, so the pixels run out first
#   in either language.
#
#   THE LINES BELOW ARE KOREAN and the labels around them are not. CLEARED,
#   ENTERING, THE MAW IS QUIET and the rest of the HUD are still English, so a
#   run currently reads its story in one language and its state in another.
#   That is a half-finished translation rather than a decision.
#
#   NO `#` INSIDE A LINE. Comments are stripped twice, by bake.ps1 on the way
#   into the binary and by txt_skip on the way out of this file, so a `#` in a
#   quoted line would survive in a dev build and vanish in the shipped one.
#   Two builds that read this file differently is exactly the failure the
#   baked-asset checks exist to prevent.
#
# 이 파일은 재빌드 없이 다시 읽힙니다. 게임을 켜 둔 채로 저장하면 다음 컷신이 새 대사를
# 사용합니다. loot.txt와 같은 이유이며, 대사는 이 프로젝트에서 가장 다시 쓰이기 쉬운
# 부분이자 재빌드를 치를 가치가 가장 적은 부분입니다.

# ---------------------------------------------------------------- the intro --
#
# Held before the first frame of a story run. Two jobs: say what the player is
# walking into, so that a fixed monster on a wall reads as a thing that was put
# there rather than as a monster that forgot to move -- and then, on the last
# page, name the controls. That page is last because it is the one the player
# should still have in front of them when the cutscene ends and they take over;
# it also holds longest, since a line of prose is read once and a control is
# read, tried, and read again.
c intro
  p
    t "첨탑이 아무것도 내려보내지 않았다"
    t "광석도 없다. 물도 없다. 소식도 없다."
  p
    t "대신 올라온 것은 굶주려 있었다"
    t "그리고 길을 알고 있었다"
  p
    t "유리탑 안에서 무언가가 먹고 있다"
    t "올라가라. 아가리를 찾아라."
    hold 5200
  p
    t "WASD로 움직인다. 좌클릭으로 쏜다."
    t "1 2 3 4 로 무기를 바꾼다."
    t "우클릭으로 갈고리를 쏜다."
    hold 7000

# -------------------------------------------------------------- the victory --
#
# Between the maw's last line and the win screen. step_boss deliberately does
# not raise `won` on the frame the boss dies so that its last sentence can be
# read, and this is the gap that opens.
c victory
  p
    t "수호석은 재가 되고 아가리는 닫혔다"
  p
    t "탑은 이제 충분히 조용해서 들린다"
    t "그것이 얼마나 아래로 뻗어 있는지"
  p
    t "그것은 결코 하나뿐이 아니었다"
    t "나머지는 이야기를 기다리지 않는다"
    hold 5000

# --------------------------------------------------------------- the defeat --
#
# After the collapse has played -- the fall is the part that says what
# happened, so nothing is drawn over it.
#
# ONE PAGE, and the count is the design rather than the writing running out. A
# player who has just died is reaching for the key that starts again, and every
# page is one more press between them and that. Dying is the common event in an
# arena; a two-page defeat would be read once and skipped for the rest of the
# player's life with the game, which is a worse outcome than saying less.
#
# 페이지 하나이며, 그 수는 글이 떨어진 것이 아니라 설계입니다. 방금 죽은 플레이어는 다시
# 시작하는 키에 손을 뻗고 있고, 페이지 하나하나가 그와 그것 사이의 누름 한 번입니다. 아레나에서
# 죽음은 흔한 사건입니다. 두 장짜리 패배는 한 번 읽히고 그 뒤로 그 플레이어가 이 게임과 보내는
# 내내 건너뛰어질 것이며, 그것은 덜 말하는 것보다 나쁜 결말입니다.
c defeat
  p
    t "수호석은 버텼다"
    t "첨탑은 다시 삼키기 시작한다"
    hold 3400
